# Projeto Calculadora — FinançApp

Esta é a branch `main`, com a versão original do projeto.

A versão refatorada está na branch `Refatoracao`.

## Sobre o projeto

Calculadora desenvolvida em Java para o FinançApp, com as operações básicas e testes de funcionamento.

## Como executar

1. Clone o repositório:
   ```
   git clone https://github.com/Vinicius-dev777/Projeto-calculadora.git
   ```
2. Abra o projeto na sua IDE Java.
3. Execute a classe principal.
